# Netflix-Movies-TV-Shows-Analysis

## Project Overview
This project analyzes Netflix Movies and TV Shows data using Microsoft Excel to understand content distribution and catalog trends.

## Objectives
- Compare Movies and TV Shows.
- Explore country-wise content distribution.
- Analyze release-year trends.
- Present insights through charts and a dashboard.

## Tools Used
- Microsoft Excel
- Data Cleaning
- PivotTables
- Charts and Data Visualization

## Project File
- `Netflix_Movies_TV_Shows_Analysis_Dashboard.xlsx` — Excel workbook containing the project analysis and dashboard.

## Skills Demonstrated
- Data organization and cleaning
- Data analysis using PivotTables
- Data visualization
- Presenting findings clearly
